# python-trainee-projects

Набор учебных проектов для отработки базовых навыков на Python.

## Day 1: Greeting App with Age Calculation

Простой консольный скрипт, который:
- запрашивает у пользователя имя и год рождения;
- рассчитывает возраст на 2024 год;
- проверяет корректность ввода (только числа, реалистичный возраст 0–120 лет).

### Как запустить

1. Клонируй репозиторий:  
   `git clone <ссылка_на_репозиторий>`
2. Перейди в папку проекта:  
   `cd python-trainee-projects`
3. Запусти скрипт:  
   `python day_01_greeting.py`

### Технологии

- Python 3.x
